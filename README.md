# 💼 Portfólio — Júlio César Silva

Portfólio pessoal desenvolvido com HTML e CSS puro.

## 🔗 Acesse
> Após publicar no GitHub Pages, o link ficará disponível em:  
> `https://jcs-silva.github.io/portfolio/`

## 📁 Estrutura
```
portfolio/
├── index.html       → estrutura da página
├── portstyle.css    → estilização
└── README.md        → este arquivo
```

## 🛠️ Tecnologias
- HTML5
- CSS3 (Flexbox, position, Google Fonts)

## 🚀 Como publicar no GitHub Pages
1. Crie um repositório no GitHub chamado `portfolio`
2. Envie os arquivos para o repositório
3. Vá em **Settings → Pages**
4. Em **Source**, selecione a branch `main` e clique em **Save**
5. Aguarde alguns minutos — o site estará disponível no link acima
